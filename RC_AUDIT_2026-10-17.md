# EPYVRA RC audit — 2026-10-17

## Outcome

All code-controlled build blockers found in this pass were fixed. The web application and Android debug application pass their automated gates. Production release remains intentionally blocked by owner/vendor configuration listed below.

## Fixed in this pass

- Updated vulnerable runtime packages and removed the unused Genkit/CLI and patch-package dependency trees.
- Reduced the production audit from 106 findings (3 critical, 32 high, 70 moderate, 1 low) to 7 (0 critical, 6 high, 1 moderate).
- Added production security headers, removed the framework disclosure header, and reduced the Server Action request ceiling.
- Replaced the cleartext GeoIP endpoint with HTTPS and encoded user-controlled IP path values.
- Restricted storage settings updates to an explicit schema instead of accepting arbitrary MongoDB fields.
- Enforced the configured upload limit on the server with a hard 200 MB ceiling to avoid unbounded memory use on the 512 MB Render service.
- Made Bunny connectivity tests remove their probe object after a successful test.
- Corrected binary buffer typing without unsafe broad casts.
- Replaced the Android placeholder API origin with `https://epyvra.com/api/mobile/v1`.
- Removed stale remote PWA placeholder icons and corrected the EPYVRA maskable icon declaration.
- Added the security suite to the Render build gate.

The remaining npm advisories are in the Tailwind 3 build graph (`braces`, `micromatch`, `chokidar`, `fast-glob`) and Next 15's bundled PostCSS. npm only offers major migrations to Tailwind 4 and Next 16. These migrations must be tested as dedicated work because forcing them into this security patch can change styling, routing, and build behavior. No advisory or lint rule is suppressed.
